# Image credits

All previews in this directory are resized and JPEG-re-encoded from the following public datasets. Original dataset files are not changed. All three sources use [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

- `tomato-01.jpg` through `tomato-18.jpg`: Elvianto Hartono, *Longitudinal RGB and Ultraviolet-Excited Tomato Imaging Dataset During 18-Day Storage*. [Zenodo record 21943147](https://zenodo.org/records/21943147), DOI 10.5281/zenodo.21943147.
- `apple-01.jpg` through `apple-18.jpg` and `catalog-1.jpg`: Aldiki Febriantono, Abba Suganda Girsang, Suharjito Suharjito, Maria Susan Anggreainy, *Manalagi Apple Disease Dataset*, version 6. [Mendeley Data](https://data.mendeley.com/datasets/9zgkwwv9j8/6), DOI 10.17632/9zgkwwv9j8.6. The 18-image replay uses different apples arranged as simulated progression; it is not a longitudinal record of one apple.
- `catalog-0.jpg`: T Bagyammal, Yogini Aishwaryaa P T S, Krishna Deepak, Devika Unnikrishnan, *TriModal Ripeness 6*, version 1. [Figshare record 30783827](https://figshare.com/articles/dataset/30783827), DOI 10.6084/m9.figshare.30783827.v1.

Source filenames and hashes for the demo observations are retained in `../demo_evidence.json`. The catalog image samples are identified in `../demo_database_evidence.json`. No endorsement by dataset creators is implied.
